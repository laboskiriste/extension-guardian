# Release notes 0.2.0

Paste into the "What's new" / release notes field of each store.

## Chrome Web Store and Edge Add-ons

```
No label means safe. Ratings now say what was found: "Attention required", "Review recommended" or "No warning signs". User count, update date and trader status are shown as context and no longer raise or lower the rating, because popular extensions are the ones most worth buying or hijacking.

Every extension now has a suggested action. Site access is judged by how far it reaches, more permissions are listed (system information, scanners, on-demand access), and the same access written another way is no longer reported as a change.
```

## Firefox Add-ons (release notes, max 250 characters shown, rest is fine)

```
Ratings now say what was found ("Attention required", "Review recommended", "No warning signs") and never that an add-on is safe. Popularity and update date are context, not trust. Each add-on has a suggested action, and more permissions are listed.
```

## Reviewer note (Firefox "Notes to reviewer", Chrome "Justification" if asked)

```
No new permissions and no change to what is sent: only extension IDs are looked up, as before. This version changes how the existing data is presented (labels, a suggested action, and scoring that no longer uses popularity or update date) and adds permission descriptions. No remote code.
```
