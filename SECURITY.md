# Security

If you find a security problem in Extension Guardian, please report it privately: open the repository's **Security** tab and click **Report a vulnerability**. Don't open a public issue for it.

I'll reply within a few days, fix it as fast as I can, and credit you in the release notes if you'd like.

Extension Guardian is part of Tinyward. Its promise is that it collects nothing about you, so anything that makes it leak data counts as a security problem.
